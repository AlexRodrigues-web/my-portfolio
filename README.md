# AlexDevCode

Site principal e portfólio profissional da **AlexDevCode**, desenvolvido em PHP, JavaScript e CSS para apresentar serviços, projetos, templates e ferramentas web.

## Principais áreas
- Portfólio e apresentação profissional
- Serviços para negócios locais e soluções personalizadas
- Templates/demos por nicho
- Radar de oportunidades para developers
- Auditoria web e relatórios
- Conteúdo PT/EN/ES e SEO técnico
- Formulários com proteções anti-spam e CSRF

## Stack
PHP · JavaScript · HTML5 · CSS3 · Composer · MySQL/MariaDB · Apache/Hostinger

## Execução local
1. Coloque o projeto em `C:\xampp\htdocs\meu-portfolio`.
2. Inicie Apache e MySQL no XAMPP.
3. Configure apenas os dados locais necessários.
4. Abra `http://localhost/meu-portfolio/`.

## Segurança
Ficheiros `.env`, credenciais SMTP, backups SQL, cache, storage e cópias locais não fazem parte do repositório. Nunca publique chaves reais.

## Produção
O projeto alimenta o ecossistema AlexDevCode e a versão pública em **alexdevcode.com**.
